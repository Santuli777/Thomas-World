Política de privacidad · Thomas's World

Última actualización: octubre de 2026.

Español

Resumen: Thomas's World no recopila, no vende ni comparte ningún dato personal.

  • Sin cuentas: no hay registro ni inicio de sesión.
  • Datos guardados: tu progreso (pantallas ganadas, trajes, monedas, idioma y ajustes) se guarda únicamente en tu propio dispositivo. No se envía a ningún servidor y se borra si desinstalás la app o borrás los datos del navegador.
  • Sin publicidad ni rastreo: el juego no muestra anuncios, no usa herramientas de análisis y no usa servicios de terceros que recopilen información.
  • Sin compras con dinero real: esta versión es gratuita y no incluye compras dentro de la app.
  • Permisos: el juego no pide acceso a la cámara, el micrófono, la ubicación, los contactos ni los archivos.
  • Niños: el juego es apto para todo público y no recopila información de nadie, incluidos los menores de edad.
  • Alojamiento: el juego se sirve desde GitHub Pages. Como en cualquier sitio web, el servidor puede registrar de forma técnica la dirección IP al descargar el juego, según la política de GitHub.

Si cambiamos esta política, publicaremos la nueva versión en esta misma página.

English

Summary: Thomas's World does not collect, sell or share any personal data.

  • No accounts: there is no sign-up or login.
  • Stored data: your progress (levels won, outfits, coins, language and settings) is stored only on your own device. It is never sent to a server and is erased if you uninstall the app or clear your browser data.
  • No ads or tracking: the game shows no ads, uses no analytics and uses no third-party services that collect information.
  • No real-money purchases: this version is free and has no in-app purchases.
  • Permissions: the game does not request access to camera, microphone, location, contacts or files.
  • Children: the game is suitable for all ages and collects no information from anyone, including minors.
  • Hosting: the game is served from GitHub Pages. As with any website, the server may technically log the IP address when the game is downloaded, per GitHub's policy.

If this policy changes, the new version will be posted on this page.
